## What's new

0.6.10 fixes crashes on older and newest Minecraft versions, a hang on weak integrated graphics, and lets a PC take back its offline name after a Windows reinstall.

### Launcher
- An offline name whose key was lost (for example after reinstalling Windows) can be taken back by the same PC. Only a salted hash of the PC's firmware ID is sent, and only when signing in with an offline name.
- Clearer diagnosis when Java's working directory can't be accessed.
- Discover shows Minecraft favicons for servers, and server forms open as a proper modal.

### In game
- Other players' cosmetics show only while they are on Arctic.
- Polarium 0.32.0 compiles its instanced pipelines in the background on 26.1.2 to 26.3, so weak integrated GPUs no longer freeze on load.

### Fixed
- The Controls screen no longer crashes on 1.14 to 1.21.8 because of the Arctic key category.
- Out-of-range key codes no longer crash 1.8.9 and other legacy versions.
- Connected glass no longer crashes when the renderer doesn't match.
