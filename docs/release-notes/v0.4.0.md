## What's new

### Arctic Client
- **Play with a controller** on every version (1.8.9 to 26.3): Xbox, PlayStation and other gamepads walk, look, fight, use the hotbar and inventory, and move a pointer through menus. Arctic → Controller sets look speed, pointer speed and inverted looking.
- **Tier Tags**: players' PvP tiers by their names, in name tags and the tab list ("HT3 Sword | Steve"), from PvPTiers or SubTiers.
- **A new server list** on every version: drag servers to reorder them, see icons, MOTDs, the ping, players (hover for who's on) and the version each server runs, find LAN worlds, and discover public servers. Lost connection? Reconnect in one click, or turn on Auto Reconnect.
- **A new minimap**: smooth instead of jumping, square or round, north-up or turning with you, with players and waypoints on it.
- **The scoreboard and the boss bar** move, resize and hide in the HUD editor like any widget.
- **Cosmetic fit**: move glasses and other face items up, down, closer or farther to sit on your skin's eyes, or wear a shoulder pet on the other shoulder. Every Arctic player sees it.
- The emote wheel shows how many pages of emotes there are (29 emotes, 3 pages).

### Launcher
- **Glass theme**: the aurora night through frosted cards and sidebar.
- **Mod clash check**: before a modded instance starts, Arctic looks for what would stop the game (the same mod twice, a mod that breaks another, a missing or too old requirement, a mod for another Minecraft version) and fixes it in one click.
- Required updates install and restart by themselves; this "What's new" shows after each update (you can turn it off in Settings).
- Portable mode also starts from a file named `portable.txt.txt` (what Windows makes of "portable.txt" when it hides file extensions).
- Server rows on the Play tab can be dragged anywhere, glide aside and scroll the page, like the game's own list.

### Fixed
- **Crashes explained right**: a damaged game file now says so (and the next start checks and fetches fresh copies), as do a memory setting the computer can't give, a full thread stack, and VulkanMod or graphics driver failures (including picking the wrong one of two graphics cards).
- **Fewer crashes**: Vulkan no longer runs out of LWJGL stack space at start; 1.21.9 to 26.3 no longer crash when someone joins or leaves while player heads load; 1.8.9 no longer crashes accepting a server's resource pack; the memory setting is kept within what the computer has.
- **Essential and other big modpacks work again on Fabric**: Arctic's faster start no longer loads game files before other mods have set up, which broke Essential ("Could not initialize class gg.essential.api.EssentialAPI") and crashed some packs at start ("Mixin transformation … failed", e.g. Cobbleverse).
- Held items follow your hand in emotes that bend the arm.
- Elytras painted from Arctic capes are no longer see-through from the side or from above.
- The Cosmetics tab's capes open without a pause.
- Button text sits in the middle of its button.
- Replays no longer fill the drive on busy servers.
- Videos aren't attempted while VulkanMod draws the game (it doesn't use OpenGL); a message says so instead of a crash.
