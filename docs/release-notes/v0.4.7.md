## What's new

### Packs and shaders
- **Browse shaders in game.** Open Packs & Shaders in Arctic's menu to find shaders on Modrinth, install them, and turn them on or off with Iris. Downloads also work before shader support is enabled; the page explains how to enable it in the launcher.
- **Filter your search.** Choose a category, resource-pack resolution or shader performance impact, and sort by downloads, relevance, newest or recently updated. Browse this Minecraft version or all versions; installation still checks compatibility with your game.

### Linux
- **Flatpak distribution with signed updates.** Install Arctic from [our Flatpak repository](https://brksfrb.github.io/arctic-launcher/). Your Linux software manager handles updates. The repository is published from Arctic's existing GitHub project.

### Fixed
- Fabric's internal mod resources no longer fill the in-game resource-pack list. Applying your choices keeps those internal resources available to the game.
- Resource packs added to the launcher's folder appear automatically while its pack list is open.
- Pack searches no longer silently fall back to a different Minecraft version when no compatible results are found.

### Download

Windows: `arctic-launcher-windows-x64.exe` · macOS: `arctic-launcher-macos.zip` · Linux: `arctic-launcher-linux-x64` or the Flatpak installer. The Windows files are signed (Open Source Developer Leyla Barlak, Certum).
