## What's new

### Fixed
- **Motion blur no longer makes the game dark** on 1.15.2 to 1.21.11. The blur mixed every frame with black, so turning it on dimmed everything.
- **Motion blur works with VulkanMod** (1.21.6 to 1.21.11), and Arctic Client with VulkanMod no longer crashes when you join a world.
- **Elytras no longer disappear with an Arctic cape.** Every Arctic cape now comes with its own matching elytra wings.
- The Arctic title screen buttons now follow the game's language.
- 26.x: motion blur can't darken the game on drivers that lose the previous frame.
