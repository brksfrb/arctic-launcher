## What's new

### Fixed
- **Big modpacks on computers with little memory**: a computer with 4 GB could give the game only 1.9 GB, too little for a large pack that opened fine in other launchers. It can now give up to all of its memory when Windows' page file can back it (slower, but it starts), and the launcher warns when a big pack gets too little.
- **A crash from too little memory** is explained as that ("Not enough memory for this many mods"), not as a damaged game file.
- **Server list ping times are right**: they showed about 100 ms too much.

### Download

Windows: `arctic-launcher-windows-x64.exe` · macOS: `arctic-launcher-macos.zip` · Linux: `arctic-launcher-linux-x64`. The Windows files are signed (Open Source Developer Leyla Barlak, Certum).
