## What's new

### Fixed
- **The launcher works on PCs where Windows can't look up website names.** Some PCs showed "No such host is known" for Mojang, Fabric or GitHub, so creating an instance and the update check failed even though the browser worked. When Windows can't find a site, the launcher now asks Cloudflare over HTTPS instead (not used behind a proxy; set `ARCTIC_NO_DOH=1` to turn it off).
- **The game no longer fails to start with a damaged `arctic-mod.jar`.** The file is checked before every start and written again when it is broken.
- **Entity hitboxes from Arctic switch on and off at once on Minecraft 1.21.11 to 26.3** (they used to need a rejoin), and Arctic's HUD widgets no longer disappear while hitboxes are on.

### New
- **Pick the modpack version.** Every modpack in the browser has a **Versions** button that lists its versions with their Minecraft version and loader; Install still takes the newest release.
