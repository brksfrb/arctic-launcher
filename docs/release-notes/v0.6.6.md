## What's new

0.6.6 is a security update for a Java bug (CVE-2026-114938, known as Java4Shell). When the game starts with Java 17 or newer on a normal Intel or AMD computer, Arctic now turns off the affected built-in Base64 shortcut. Java 8 (used by 1.16.5 and older), ARM computers, and Apple Silicon (including Rosetta) are not affected.

There are no other changes from 0.6.5.
