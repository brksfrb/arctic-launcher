## What's new

0.6.2 adds translations and fixes a few crashes and blurry bits from 0.6.1.

### New
- **14 languages** for the launcher and the Arctic Client. Arctic uses your system language when it can, and English otherwise (English, Turkish, German, French, Spanish, Portuguese, Italian, Dutch, Polish, Russian, Ukrainian, Chinese, Japanese and Korean).

### Fixed
- **1.8.9 no longer crashes at startup** when connected glass looks at a resource pack with no file on disk. The game keeps vanilla glass and writes the bad pack to the log.
- **Closing the game with Force close** is no longer reported as a crash, and no longer tells you to check your antivirus.
- **Tab-list ping** numbers are drawn on whole pixels, so they stay sharp.
- **The in-game logo and the nametag badge** are sharp.
- If Windows kills a frozen game, the crash report now keeps a short record from a few seconds before that, so the hang can be investigated.
