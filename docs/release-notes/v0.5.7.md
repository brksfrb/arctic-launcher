## What's new

### Fixed
- **The launcher reaches its servers on more PCs where Windows can't look up website names.** When Windows can't find a site, the launcher now asks Cloudflare, Google and Quad9 over HTTPS at the same time (whichever isn't blocked answers first), and if all of them fail it uses the address the site had the last time it was found. The error message now says when those lookups were blocked too. Not used behind a proxy; set `ARCTIC_NO_DOH=1` to turn it off.
