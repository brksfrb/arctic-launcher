## What's new

### Arctic Client (in game)
- **The smooth font works on every version now**, 1.8.9 to 26.3. Turn on **Fancy** (Arctic → Style, or the launcher's Settings) to use it. Text stays sharp at any GUI scale. Characters the font doesn't cover keep Minecraft's own font.

### Fixed
- **1.8.9 starts again with Arctic Client** (a cosmetics change in 0.3.0 stopped it at launch).
- **1.15.2 starts again with Arctic Client.**
- **1.16.5 with Performance on** no longer stops at "EntityCulling requires fabric".
- Text lines up with the buttons beside it across the launcher, and all buttons are the same height.
- "Restart now" after an update can no longer leave a frozen launcher window behind.

### Download

Windows: `arctic-launcher-windows-x64.exe` · macOS: `arctic-launcher-macos.zip` · Linux: `arctic-launcher-linux-x64`. The Windows files are signed (Open Source Developer Leyla Barlak, Certum).
