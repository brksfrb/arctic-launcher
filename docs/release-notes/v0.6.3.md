## What's new

0.6.3 fixes startup crashes and crash messages.

### Fixed
- Fixed a startup crash on Minecraft 1.15 to 1.19.2 (Fabric) caused by Arctic's connected glass.
- Fixed a startup crash on Forge 1.8.9 with older Mixin caused by Arctic's connected glass.
- Crashes where a mod's mixin fails to load are now named correctly instead of "A mod is for a different version".
