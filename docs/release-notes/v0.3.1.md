## What's new

**Updates install themselves.** The launcher now downloads and installs new versions on its own and uses them the next time you open it. If it's waiting in the tray with no game running, it switches over right away and stays in the tray. A launcher left open checks again every few hours. After an update you'll see a short "Updated to …" note with a link to what's new. You can turn this off in Settings → Updates → "Install updates automatically".

**Fixed**
- The in-game Mods menu now opens with an empty search. A search left over from earlier could hide mods such as Motion Blur and Item Physics.
