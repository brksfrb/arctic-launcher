## What's new

### Fixed
- **Fabric file repair now reaches the mod loader.** After a missing-library crash, the repair could finish after checking only vanilla files, leaving a damaged Fabric or Mixin library in place. It now checks both stages and keeps the repair pending if preparation fails.
- **Play checks Fabric's key libraries automatically.** Damaged copies with a published checksum are replaced even when an older launcher did not request a repair.
- **Missing-library crashes keep their actual explanation.** A large modpack on a computer with little memory no longer causes this error to be relabeled as insufficient memory or disables its automatic repair. Memory warnings remain available before launch.

### Download

Windows: `arctic-launcher-windows-x64.exe` · macOS: `arctic-launcher-macos.zip` · Linux: `arctic-launcher-linux-x64`. The Windows files are signed (Open Source Developer Leyla Barlak, Certum).
