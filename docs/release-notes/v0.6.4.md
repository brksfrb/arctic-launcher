## What's new

0.6.4 makes Forge installs survive Forge's download server being slow or missing files, adds world favourites and a world trash, and makes joining and the HUD lighter.

### Worlds
- Star worlds to pin them to the top of the list. Starred worlds can't be deleted until you unstar them.
- Deleted worlds go to a world trash for 14 days, where you can restore them or delete them for good.

### Servers and menus
- Direct Connection has an "Add to list" button.
- The same server no longer shows up twice in the server list, and server ping is more accurate.
- Duplicate Mods menu cards (Scoreboard, Held Item) are merged into one card each.

### Performance
- Lighter minimap, cosmetics cached between sessions, and cape/cosmetic textures decoded off the render thread on 1.8.9.
- HUD text is only laid out again when it changes, and 1.8.9 HUD shapes are drawn in batches.

### Fixed
- Forge installs no longer fail when Forge's download server is slow or returns "not found": downloads wait longer, retry, and fall back to a mirror for files whose checksum is known.
- Fixed a Forge 1.8.9 crash with connected glass (UnpackedBakedQuad).
- Damaged Fabric loader files are detected and repaired.
- Patcher no longer blocks launching when its OneConfig download fails.
- Fixed the Language dropdown showing twice in Settings.
- Better crash messages: mixin clashes and Forge registry mismatches name the right mod, and crash reports carry clearer evidence.
