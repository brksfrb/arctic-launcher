## What's new

### Fixed
- **Big Fabric modpacks start again with the Arctic Client** (COBBLEVERSE and others on Fabric Loader 0.18 or older): the game no longer crashes at start with "Mixin transformation … failed" / "ArrayList cannot be cast to AnnotationNode".
- **Modpack downloads no longer hang**: one stalled connection used to hold a big download (a 239 MB modpack, say) for over an hour. Big files now arrive in small pieces, and a piece that stops is fetched again on a fresh connection.

### Launcher
- **Choose where Arctic keeps its files**: Settings → Storage moves everything (game files, Java, worlds, accounts, settings) to another folder or drive, and the first start asks too. Each instance can also keep its worlds, mods and packs in a folder of its own, or use an existing .minecraft folder as it is.
- **Quick tips** in the sidebar: one of Arctic's features at a time, a new one every few minutes; click to open it. Settings → Show quick tips turns them off.

### Download

Windows: `arctic-launcher-windows-x64.exe` · macOS: `arctic-launcher-macos.zip` · Linux: `arctic-launcher-linux-x64`. The Windows files are signed (Open Source Developer Leyla Barlak, Certum).
