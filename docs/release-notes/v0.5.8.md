## What's new

- **Import from SKlauncher.** Arctic finds SKlauncher 3.x profiles (with its memory setting, even for versions it hasn't downloaded yet) and SKlauncher 4.x instances, including ones in a moved data folder, and copies them in. Accounts are never read.

### Fixed
- **Play together finds your world on more PCs.** The launcher now listens for the game's "Open to LAN" announcement on every network adapter (a VPN, Hamachi, WSL or a virtual adapter used to hide it), and if none arrives it reads the port from the game's log and checks that a Minecraft server answers there. Nothing changes if it already worked for you.
