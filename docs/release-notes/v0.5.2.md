## What's new

### Fixed
- **An offline name is never lost.** Every offline key is now also kept in two backup copies, restored from them if the main file ever lacks it, and a file that can't be read is set aside instead of overwritten. Before a key counts as lost, every key saved on this PC is tried (older ones, other profiles, backups). This fixes "this name is used by another Arctic player" after an update.
