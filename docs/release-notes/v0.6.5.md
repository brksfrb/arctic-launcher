## What's new

0.6.5 starts on a clean Windows PC without the Visual C++ runtime, adds Discover for browsing and installing content, and lets you put a desktop shortcut on an instance.

### Windows
- The Windows launcher and command-line tool now start on a fresh PC without installing the Visual C++ redistributable. This was the "VCRUNTIME140.dll was not found" error.

### Discover and instances
- Discover is a new content browser: pick a version, install data packs, and install several things at once.
- Each instance has a "Create desktop shortcut" action. On Windows it makes a shortcut on your Desktop (including a Desktop moved to OneDrive). On Linux it makes a .desktop file, and on macOS a .command file. Opening it starts that instance with your current account, using the launcher if it is already open.
- You can launch the same instance more than once.
- Settings › About has a "See all features" link.

### Play together
- Offline friends can join (on by default for invites).
- Hosted worlds now have /ban, /pardon, /banlist and /ban-ip.

### Fixed
- The launcher repairs a Java runtime that was left half-copied, which stopped the game starting.
- Fixed crashes from Persistent Chat restore, stale Performance mods after switching versions, Held Item on 1.15, and EntityCulling on 1.16.
- Missing performance-mod dependencies are repaired, and custom RAM flags in the Java arguments are now respected.
- Arctic Client is skipped on Quilt when its Fabric compatibility is too old.
- Crash reports now name the mod that caused the crash, include total and free RAM, catch vanilla startup crashes that could not save a report, and link Windows native crashes to Windows' own error reports.
- Resource packs on 1.8 to 1.12 and in shared folders are applied correctly, and shared game options are kept when the file format changes.
- A one-time notice appears when the game is not started by Arctic Launcher.
- CurseForge imports are blocked. Replay and gameplay video are off by default. The Submit server screen shows the listing requirements, and the duplicate Performance description is removed.
